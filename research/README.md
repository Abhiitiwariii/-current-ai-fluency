# Research

Working folder for research on this case study.

## Structure

| Folder | What goes here |
|--------|----------------|
| `sources/` | Raw source material — PDFs, saved articles, links, references |
| `notes/` | Your working notes, summaries, and annotations per source/topic |
| `data/` | Datasets, spreadsheets, extracts, anything analyzable |
| `drafts/` | In-progress writeups |
| `outputs/` | Finished deliverables |

## Files

- `research-log.md` — running log of what was done, when, and what was found
- `questions.md` — the research questions driving this work
- `sources/sources.md` — bibliography / source tracker

## How to use

1. Define the questions in `questions.md`.
2. Collect material into `sources/`, logging each in `sources/sources.md`.
3. Take notes in `notes/`, one file per source or theme.
4. Analyze in `data/`, draft in `drafts/`, ship from `outputs/`.
5. Keep `research-log.md` current so the trail is reproducible.
